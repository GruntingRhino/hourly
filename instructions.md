# GoodHours Claude Instructions

## Version 1.0
- When a school creates an account, automatically list it as a private beneficiary, so students of that school can sign up for school listed opportunities.
- In the create opportuntiy screen, change the field title "Location" to "Location of Opportunity"
- When a beneficiary creates an opportunity, in the location field by default it should put in the beneficiary's address, and then the user can change if necessary.
- When a created opportunity is happening in the future, it should be listed as "Upcoming," when the opportunity is happening in the present it should be listed as "Active," when the opportunity is already finished it should be listed as "Expired."
- On the create opportunity page, move the created opportunity list to the right as a vertical panel.
- On the bottom of the create opportunity page, create a panel with all approved schools, and the option to choose which schools can participate in the opportunity. By default select all schools.
- In the create opportunity page, remove the "Hours" field. Hours should be automatically calculated based on the start and end times of the opportunity.
- In the create opportunity page, rename "Cap" to "Maximum # Volunteers"
- In the landing screen, the "For Students" panel should not be red in color, make it blue like "For Schools" and "For Community Partners"
- At the bottom of the landing screen remove the text "GoodHours is free for schools ..." Just keep "Ready to get started? Sign in with Google to Register"
